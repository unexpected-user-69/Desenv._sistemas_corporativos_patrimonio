# Desenvolvimento de Sistemas Corporativos - Patrimônio

Este é um projeto de API para gestão de patrimônio corporativo.

## Tecnologias

- Node.js
- NestJS
- TypeScript

## Como executar

bash
npm install
npm run start:dev


## Workflow CI/CD

Este projeto utiliza GitHub Actions para CI/CD com os seguintes jobs:
- Lint
- Build
- Test
